### **.l文件结构
（用%%分隔区域）

定义区：选项、C 头文件、正则表达式的命名定义

%%

规则区：正则表达式及对应的 C 动作

%%

用户代码区：main 等 C 函数

**详细结构**
```
├── 定义段（%{ ... %}）
│   ├── 头文件包含
│   ├── 全局变量（g_out 输出文件指针）
│   └── emit() 函数（输出 Token）
├── 选项声明
│   ├── %option noyywrap   不依赖 yywrap
│   └── %option yylineno   自动维护行号
├── 正则别名定义
│   ├── DIGIT, LETTER, ID, INTCONST, STRCHARS
│   └── 多行注释起始条件 %x ML_COMMENT
├── 规则段（%% ... %%）
│   ├── 多行注释 /* */ 规则
│   ├── 单行注释 // 规则
│   ├── 格式字符串规则
│   ├── 关键字规则（12个）
│   ├── 标识符规则
│   ├── 数字常量规则
│   ├── 双字符运算符规则
│   ├── 单字符运算符/界符规则
│   ├── 空白符规则
│   └── 非法字符规则（报错不中断）
└── 用户代码段
    └── main()
        ├── 打开 testfile.txt 和 output.txt
        ├── 调用 yylex() 启动扫描
        └── 关闭文件
```
